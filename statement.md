Project Statement

## Problem Statement

People may not know whether a password meets basic strength requirements or how to improve it.

This project provides a simple program that checks a password and suggests which requirements are missing.

## Scope

The project checks passwords for basic length and character requirements. It does not verify whether a password is reused, easy to guess, or exposed in a data breach.

## Target Users

- People creating or reviewing passwords
- Students learning basic Python programming

## High-Level Features

- Check for a minimum length of 15 characters
- Check for digits, uppercase and lowercase letters, and special characters
- Show how many requirements are met
- Display a strength rating
- Suggest ways to improve the password
