Password Strength Checker

## Overview

The Password Strength Checker is a Python program that checks a password and gives suggestions to help make it stronger.

## Features

- Check password length
- Check for digits, uppercase and lowercase letters, and special characters
- Show password strength
- Suggest missing requirements

## Technologies Used

- Python
- VS Code

## How to Run

1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

```text
python password_checker.py
```
